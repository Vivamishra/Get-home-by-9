# Get Home by 9

A small browser-based 3D horror street scene and starting point for the game.

## Run it

Open `index.html` in a modern browser, or serve this folder with a local static web server. The scene uses Three.js from jsDelivr and Google Fonts, so an internet connection is needed to load those assets.

## Current prototype

- A first-person residential street blockout with houses, sidewalks, streetlights, trees, a parked car, and distant night sky.
- Atmospheric fog, moonlight, flickering amber street lamps, vignette, and subtle film grain.
- Controls: **WASD** to walk, **mouse** to look, **Shift** to move faster, and **Esc** to release the mouse.
- Click **Sound: OFF** to enable a quiet synthesized ambient drone.

This is a visual foundation rather than a complete game: the objective, story events, and gameplay systems can be built on top of this scene.
